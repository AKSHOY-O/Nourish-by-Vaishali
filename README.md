# Nourish by Vaishali

A responsive dietitian portfolio website for Vaishali, featuring personalised nutrition services, a professional portrait section, FAQs, and direct phone and WhatsApp contact options.

## Features

- Responsive desktop and mobile design
- Professional “Meet Vaishali” portrait section
- Nutrition services and consultation journey
- Direct call and WhatsApp actions
- Accessible semantic page structure
- GitHub Actions build verification

## Run locally

Requirements: Node.js 22.13 or newer and pnpm.

```bash
corepack enable
pnpm install
pnpm dev
```

Open the local URL shown in the terminal.

## Production build

```bash
pnpm build
```

## Main files

- `app/page.tsx` — website content and page structure
- `app/globals.css` — complete visual design and responsive styling
- `public/vaishali-portrait.png` — Vaishali’s portrait
- `public/nourish-hero-premium.png` — nutrition hero image
- `package.json` — scripts and dependencies

## Upload to GitHub

### GitHub Desktop

1. Open GitHub Desktop.
2. Choose **File → Add Local Repository**.
3. Select this folder.
4. Click **Publish repository**.

### Command line

Create an empty repository on GitHub, then run:

```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```
